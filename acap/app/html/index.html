Settings
View area
Which view the detector runs on. The boxes are drawn on the same view, so the picture and the detections cannot drift apart. A view area is a crop: the detector sees only that region, at better effective resolution. Changing this restarts the app.
Box colours
By class draws people green, vehicles blue, animals purple and everything else amber, matching the class list. One colour draws every box red, which is quieter when only one class is selected.
Confidence55%
Detections below this are discarded. Scores land on steps of about 4 points — the score tensor is 8-bit.
IoU45%
How much two boxes may overlap before the weaker one is suppressed.
Max area85%
Drops boxes covering more of the frame than this. On close scenes the model emits a stable frame-filling box that overlap suppression cannot reach. 100 turns the filter off.
Event output
tnsaxis:CameraApplicationPlatform/YOLOv8Detector/Detection One camera event, which any VMS that already consumes Axis events can subscribe to. Data: class (string), confidence (double).
Reinstalling the app resets every value here to its default. Check this panel after each upload.
